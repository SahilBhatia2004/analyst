SETUP COMMANDS
==============

1. Setup Frontend:
   > setup-frontend.bat

2. Setup Backend:
   > setup-backend.bat

3. Start Application:
   > start-dev.bat

4. Access Application:
   Frontend: http://localhost:3000
   Backend:  http://localhost:8000


QUICK START
===========

1. Run setup scripts (one time)
2. Create Supabase storage bucket "files"
3. Start development servers
4. Open http://localhost:3000
5. Sign up and start analyzing!
